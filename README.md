# BoardGame Dice Hub

An interactive digital dice rolling suite designed for Snakes & Ladders, Ludo, and traditional tabletop board games.

## Features

- Realistic multi-dice rolling animations with physics timing
- **Dedicated game modes**: Dedicated game modes: Snakes & Ladders mode and Ludo mode
- Selectable dice counts (1 single die or 2 simultaneous dice)
- Integrated audio rolling sound effects with mute toggle
- Roll history log displaying past scores and combinations
- Built-in game guide detailing Snakes & Ladders tips and Ludo rules

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Tailwind CSS
- Font Awesome
- Web Audio API

## Installation & Setup

This is a standalone, client-side web application. No complex build pipelines, database configurations, or package installations are required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SSManikandaprabu/Board-Game-Dice-Roller.git
   cd Board-Game-Dice-Roller
   ```

2. **Run the application:**
   - **Direct Browser Launch**: Double-click `dice_roller_for_snakes_ladders_and_ludo.html` to open it directly in any modern web browser (Chrome, Firefox, Safari, Edge).
   - **Or via Local HTTP Server**:
     ```bash
     python -m http.server 8000
     ```
     Then open [http://localhost:8000/dice_roller_for_snakes_ladders_and_ludo.html](http://localhost:8000/dice_roller_for_snakes_ladders_and_ludo.html) in your browser.

## Usage

1. Launch the application in your browser following the setup instructions above.
2. Interact with the application controls and input fields tailored for BoardGame Dice Hub.
3. Preferences and data are stored locally in your browser's LocalStorage where applicable.
